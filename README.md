# 북평데이 그림일기

휴대폰으로 사진을 찍으면 Gemini 이미지 AI가 **크레용 낙서** 또는 **픽사풍 3D** 그림으로 다시 그리고,
"2026.10.29 목요일", 해, "북평데이" 글씨와 낙서를 얹어 4:5 그림일기 JPG로 만들어 주는 웹사이트입니다.

주소: https://witconlab.github.io/bukpyeong-diary/

## 쓰는 법

1. 휴대폰에서 위 주소를 열고 "홈 화면에 추가"를 해 둡니다.
2. 처음 한 번 **설정 · Gemini API 키**를 열어 키를 넣고 저장합니다. 키는 그 휴대폰 브라우저에만 저장됩니다.
3. 그림체를 고르고 **사진 찍기·고르기**를 누릅니다. 10~40초 뒤 완성됩니다.
4. **사진첩에 저장**을 누르고 공유 창에서 "이미지 저장"을 고릅니다.

## 개인정보

- 이 사이트에는 서버가 없습니다. 사진은 휴대폰에서 Google Gemini API로 바로 전송되고, 이 사이트나 저장소에는 저장되지 않습니다.
- 아이 사진이 학습에 쓰이지 않도록 **결제가 연결된 유료 API 키**를 쓰세요. 무료 키로 보낸 내용은 Google 서비스 개선에 쓰일 수 있습니다.
- 다른 곳에서 키가 쓰이지 않도록 Google Cloud 콘솔에서 API 키에 웹사이트 제한(`https://witconlab.github.io/*`)을 걸어 두세요.

## 구성

- `index.html` 한 파일이 사이트 전체입니다. 그림 지침(크레용 / 픽사풍)은 파일 안의 `PROMPTS`에 있습니다.
- 날짜와 문구는 파일 안의 `DATE_TEXT`, `TITLE_TEXT`에서 바꿀 수 있습니다.
